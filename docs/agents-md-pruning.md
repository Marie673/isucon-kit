# AGENTS.md を短く保つ

**考え方・攻める基準・価値観は削らない。短さを理由に解き方を消さない。** 短くするのは、道具に移せる禁止と、skill に移せる手順だけ。
AGENTS.md の先頭は解き方にする。禁止は最後に置き、失格・減点・迷惑に当たるものだけにする。
`tests/doc-baseline.json` の大きさより 20% 以上減らすときは、消す文と理由を確かめてから基準を更新する。

AGENTS.md は、考え方と守る境界だけを書く。
役の名前・道具のオプション・時刻を含む手順は skill か docs/DECISIONS.md へ置く。
道具で拒否できる条件は道具へ移す。
同じ文を複数の入口に置かない。

追加する前に、別の過去問でも意味が通るかを確かめる。
手順を削るときは移した先への入口を残す。
展開後のパスが実在することを tests/test_bin.py で確かめる。
