# フラグ台帳

環境変数で切り替えるフラグを、1 つ 1 行で書く。コードに足したら、同じ PR でここに行を足す（`flags new NAME`）。
消したら、状態を `削除済` にする。行は消さない（なぜ消したかが残る）。`flags lint` が、この表とコード・設定ファイルのずれを出す。

| 列 | 書くこと |
| --- | --- |
| 名前 | 環境変数の名前。バッククォートで囲む |
| 既定値 | 環境変数が無いときの値（コードの既定） |
| 本番の値 | 競技サーバーに入れている値。未設定なら `-` |
| 目的 | 何を速く（安全に）するためか。1 行 |
| 根拠（PR / 計測） | PR 番号と、効果を見た計測（ベンチの id、前 → 後の数字） |
| 入れた時刻 | `2026-10-31 14:05` の形 |
| 消す条件 | どうなったら消すか。「恒久化したら」「効果が出ないと分かったら」など、判断できる形で。空は lint が指摘する |
| 状態 | `試験中`（効くか確かめている）/ `有効`（採用）/ `無効`（切ってある）/ `削除済`（コードから消した） |

状態が `試験中` のまま何時間も経つものは lint が指摘する（既定 3 時間）。採用か削除かを決める。

| 名前 | 既定値 | 本番の値 | 目的 | 根拠（PR / 計測） | 入れた時刻 | 消す条件 | 状態 |
