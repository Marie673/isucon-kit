# 比較の決め方

仮説・変えるもの・予想するプロファイル・撤回の条件を先に書く。
条件を label に記録し、できれば交互に流す。
`tools/noise/noise -f results/SCOREBOARD.md band --label <条件>` で1本単位のぶれを見る。
`tools/noise/noise -f results/SCOREBOARD.md compare A B` は Welch の平均の差の95%信頼区間を使う。
交互で同じ本数なら `--paired` で入力順に対にする。
失格は分けて残す。都合のよい走行だけを選ばない。

信頼区間が0を含む場合、効果を確定したとは言わない。
追加できる本数があれば同じ条件を追加する。
本数に限りがあれば、狙った処理の CPU・待ち時間・スコアの項ごとの数字が予想どおり動いたかを照らす。
仕様とデータの安全性、初期化、再起動も見る。
根拠が揃えば暫定で採用し、撤回の条件を作戦ボードに残す。
根拠が割れたら戻しやすい版を保ち、未解決として次の測定へ残す。
