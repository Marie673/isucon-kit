# 1件を渡す

作戦ボードの1行、触るパス、目的、確かめ方を渡す。
ブランチの worktree を使い、main に書かせない。
返させるものはブランチ名、短い要約、テスト結果と根拠にする。
常駐する役を置かない。

## 取り込む前に

1. `bin/isu-intake <branch> --paths <宣言したパス...>` を通す。
2. 宣言の外、永続化の設定、静的ファイルの変更があれば取り込まない。必要な変更なら主ループで別に判断して記録する。
3. 差分を読み、仕様・初期化・データが残る条件を確かめる。
4. 関係するテストを通してから merge する。
5. 作戦ボードを更新し、skill portal-bench で結果を確かめる。

Claude Code の subagent を使える。
Codex では利用可能な subagent か `codex exec` に同じ依頼を渡す。
