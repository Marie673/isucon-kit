## 時間割

- [ ] 序盤: 制約を測る、0 ベースの設計の骨格、ベースライン
- [ ] 情報が揃ったら 構成の判断（メインエージェントが自分で。基準は制約に最も合う設計）
- [ ] 判断の後〜 ボトルネック表の上から回す（作り直しは今のバージョンを止めずにブランチで）
- [ ] 前提の見直し（前提が崩れたらその場で）・試験中のフラグの片付け
- [ ] 再起動試験①
- [ ] 凍結 → 最終ベンチ（`tools/stop-rule/stop-rule`） → 計測の停止・SSH の終了

時刻は `docs/RULES.md` の時刻表に合わせる。
