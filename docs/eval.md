# キットの評価

公開された過去問を private の競技リポジトリへ展開する。
同じ資源・時間・初期状態で通す。
一度に変える条件は1つにする。
条件の順番を交互にし、複数回走らせる。
人間が事前に決めた費用の範囲を守る。

1. kit-new で展開する。環境とルールを埋める。
2. doctor、kickoff、main-loop、finalize の順に回す。
3. スコアと時刻を private 側の表へ残す。
4. 改善した条件が変わったかをプロファイルと項ごとの数字で確かめる。

| 通し | 条件 | コードの commit | スコア・合否 | ボトルネックを当てた時刻 | main への取り込み時刻 | 結果が表に載った時刻 | 取り込みから記録までの秒 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

ボトルネックを当てた時刻には、後の測定で支持された最初の判断の時刻を書く。
失敗した通しも除かない。
公開するキットへ結果・固有名・問題の解法を戻さない。
