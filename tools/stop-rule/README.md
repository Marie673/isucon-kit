# stop-rule

最終スコアが「最後に流した 1 本の点」で決まる回に、最終ベンチをどこで止めるかを期待値で決める。

```sh
# 同じ版で測った点（fail は 0）と、締め切りまでに流せる残りの本数
tools/stop-rule/stop-rule --scores 584535,549096,548654,556170 --remaining 3
# 直前の 1 本で止めるか（exit 0 = 止める、10 = もう 1 本）
tools/stop-rule/stop-rule --scores 584535,549096,548654,556170 --remaining 2 --last 556170
```

- 残り k 本の閾値は `V_1 = 平均`、`V_k = E[max(X, V_{k-1})]`。直前のスコアが閾値以上なら止め、下回ればもう 1 本流す。残りが減ると閾値は下がる。
- スコアの一覧は、凍結の版（同じ commit）で測ったものだけを使う。版を変えたら一覧を作り直す。
- 残りの本数は、締め切り（反映や接続を止める時刻）までの時間 ÷ 1 本の所要（待ち行列を含む）で数える。
- マニュアルの最終スコアの決め方が「最高の点」や「平均」なら、この道具は要らない。
