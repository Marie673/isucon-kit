# 1行を進める

作戦ボードの行、宣言したパス、検証方法を読む。
ブランチの worktree で実装する。
パスの外へ広がるなら依頼元へ根拠を返す。
関係するテストを通す。
変更したパスだけを stage してコミットする。
ブランチ名・変更の要点・テストの結果を返す。
反映とベンチは main の主ループに集める。
主ループで実行している場合は skill main-loop へ戻る。
判断は「見たもの → 考え → 決めたこと」で残す。
